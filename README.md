# Academic-Fees-Management-System-AFMS-
An academic fees management system developed as a second-year university project.
## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Features
- Student registration
- Fee management
- Payment records
- Student information management
- Admin dashboard

## My Role
I was responsible for database design and backend development.

## How to Run
1. Install XAMPP
2. Start Apache and MySQL
3. Import database.sql into phpMyAdmin
4. Copy the project into htdocs
5. Open the project in a browser
